# win-tools-scripts

Windows 系统一键脚本工具集（.bat），配套便携工具箱使用。

## 下载方式

所有脚本以 **Release** 形式发布，请前往右侧 **Releases** 页面下载对应版本附件，例如：

```
https://github.com/2270326963-jpg/win-tools-scripts/releases/download/v1.0/xxx.bat
```

## 使用方法

1. 下载 `.bat` 文件
2. **右键 → 以管理员身份运行**（多数脚本需要管理员权限）
3. 按窗口提示操作

## 安全说明

- 所有脚本均为**明文**，下载后可用记事本直接查看内容，确认无误再运行；
- 每个 Release 会附 **SHA256 校验值**，下载后建议用 `Get-FileHash` 核对，防止传输中被篡改；
- Windows 可能对未签名脚本弹出 SmartScreen 提示，属正常现象，核对校验值后放行即可。

## 目录规划

| 目录/命名 | 用途 |
|---|---|
| `system-*.bat` | 系统配置类（更新策略、服务设置等） |
| `tool-*.bat` | 工具辅助类（配合工具箱内软件使用） |
| `fix-*.bat` | 修复类（系统异常、网络等） |
